Gemini Live Audio Sanity Check

v1.0 Standalone

Direkt sanitetstest av NDI Virtual Webcam / vMix ljudström mot Google Gemini Live Translate API

DSP AVSTÄNGD (Råsignal)
16 kHz • 16-bit PCM • Mono
Isolerat Sanitetstest (Bypass LiveKit, WebRTC-gateways & Cloudflare)

Detta verktyg fångar rått ljud från din NDI/vMix-ingång, resamplar det inline i webbläsaren via AudioWorklet till 16 kHz 16-bit PCM Little-Endian, och skickar det i 100 ms-paket direkt till Geminis WebSocket. Tvåstegsflödet (Inspelning → Sändning) eliminerar rundgång och ekoproblem.
